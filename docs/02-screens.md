# Screens & Features

## 1. Home (/)
Customer landing page. Shows salon identity, open/closed status, people waiting, available barbers, estimated wait, team cards and Join Queue CTA.

## 2. Join Queue (/join)
Name and 10-digit phone validation; choose 1–3 active services; choose Any barber or a named barber; live service total, duration and price; Confirm creates a token and opens My Status. Existing active phone number reuses the current token.

## 3. My Status (/status)
Large token, queue position, estimated wait, status and visit details. Called status displays the assigned barber. Customer can cancel their spot.

## 4. Reception (/reception)
Queue counts, barber cards, Call next, waiting list, Add walk-in, No-show and Cancel actions. Call next respects barber preference.

## 5. Barber View (/barber)
Each barber sees current assigned customer, token and services. Start changes status to In chair; Done completes the token. Barber can toggle break.

## 6. TV Display (/display)
Large readable barber columns showing current token and availability, plus next five waiting tokens.

## 7. Owner Settings (/admin)
Open/close online queue, toggle services, add services, toggle barbers on duty and view daily counts.
